📌 Employee Payroll Management System

A web-based Employee Payroll Management System developed using Java, JSP, Servlets, and Oracle Database.
This application allows administrators to manage employee payroll records efficiently.

🚀 Technologies Used

Java (JDK 17/21)

Jakarta Servlet (Tomcat 10.1)

JSP

Oracle Database (XE)

JDBC

Eclipse IDE

Apache Tomcat Server
